# 💼 MERN Job Portal

A modern full-stack Job Portal web application built using the MERN stack.  
The platform enables candidates to search and apply for jobs while recruiters can post jobs, manage applications, and handle hiring efficiently.

---

## 🚀 Features

### 👨‍💻 Candidate Features
- User Authentication (Signup/Login)
- Browse and search jobs
- Apply for jobs
- Update profile information
- Upload resume
- View applied jobs
- Responsive user interface

### 🏢 Recruiter Features
- Recruiter authentication
- Create and manage companies
- Post job openings
- Manage posted jobs
- View applicants
- Accept or reject applications

### 🔐 Security & Authentication
- JWT Authentication
- Protected Routes
- Password hashing using bcrypt
- Role-based authorization

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository
### 2️⃣ Navigate to Project Folder
# 🔧 Backend Setup
### Move to server directory
### Install dependencies
### Create `.env` file inside `server` folder
```env
PORT=8000
MONGO_URI=your_mongodb_connection_string
SECRET_KEY=your_jwt_secret_key

CLOUD_NAME=your_cloudinary_cloud_name
API_KEY=your_cloudinary_api_key
API_SECRET=your_cloudinary_api_secret
```
### Run Backend Server
# 🎨 Frontend Setup
### Open new terminal and move to client directory
### Install dependencies
### Run Frontend
